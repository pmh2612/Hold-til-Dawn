# Hold 'til Dawn (prototype)

Godot **4.7.2** (the standard editor; no .NET needed). All game scripts, tests and art tools are GDScript. The code is split into one file per owner, in the folder of the old C# partial file.

- **Client** (`main.gd`, class `Main`): the frame loop, input, camera, snapshots and the drawing helpers. Every other part of the client is its own file, a `RefCounted` that reaches back through `main`: `src/world/view/` (world drawing), `src/ai/view/`, `src/gameplay/view/`, `ui/gameplay/` (HUD panels), `ui/menu/` (menu, lobby, pause) and `src/dev/dev_args.gd` (the playtest flags).
- **HUD** (`ui/gameplay/hud.tscn`): one `HudLayer` node per layer (world overlay, workbench, status, minimap, team markers, hotbar, build menu, bag, hurt flash), drawn in the scene's order; `ui/gameplay/hud.gd` says what each layer draws. The pause overlay and the result screen are ordinary Control scenes with real buttons (`ui/menu/pause_screen.tscn`, `ui/menu/result_screen.tscn`), laid out in the editor.
- **Rules** (`game_sim.gd`, class `GameSim`, server only): the match state, the shared data tables (`ITEMS`, `RECIPES`, door positions...) and the public API (`action`, `tick`, `snapshot`...). The rules themselves are static parts that take the match as `sim`: `src/gameplay/sim_*.gd` (players, inventory, towers, walls, construction, tactical items), `src/ai/sim_*.gd` (enemies, bosses, night spawns, roamers, drops), `src/world/sim_*.gd` (world, supplies) and `src/match/sim_phases.gd` (day, dusk, night, win and loss). Each part file names its old C# path.
- **World** (`src/world/world_geometry.gd`, class `WorldGeometry`): the island data, collision, movement and navigation; each place is built by its own static part, `src/world/world_*.gd` (cave, landmarks, lookouts, rivers, home farms...).

The C# version is kept on the `csharp-demo` branch.

## Run
- Open the project in the Godot 4.7 editor (the standard or the .NET build both work). Commands below use the Godot executable as `godot`.
- **Play:** open the project in Godot, press Play, choose a role, click **PLAY**, add bot teammates in the lobby, then **Start**.
- **Multiplayer is removed for now** so the team can finish the gameplay first. The networked version (ENet host/join, dedicated server, network test) is kept in git commit `cf44b5f` ("Port to C#"). `GameSim` still exposes the same API (`AddPlayer`, `RemovePlayer`, `Input`, `Action`, `Tick`, `Snapshot`) so the network layer can be added back on top.
- The lobby leader (first to join) picks the mode and presses **Start** (needs at least one Engineer).

## Controls
WASD move, mouse aim, LMB attack with the selected weapon (bows shoot toward the cursor), E hold 2 s with a crafted key to unlock an expedition chest, then select loot / C at the radio table opens its panel, then press E once to repair it over 5 s / gather / repair door or tower (Engineer, needs the hammer) / revive / pick up a dropped item, 1-4 or mouse wheel select a hotbar slot, Tab inventory and (at the base chest) base storage / (at an unlocked island chest) its eight storage slots with drag and drop, G give the selected stack to a teammate in reach or drop it, Q bandage, C workbench (number keys or click; most crafts take 3 s), RMB healing flask (Healer), F (hold 2 s, Engineer at night) enter or leave the base through a closed door, V skip-day vote, T choose a tower position (Engineer), LMB confirm, RMB/Esc cancel; construction takes 6 seconds, M large map (the minimap in the top left follows you), Ctrl + wheel zoom, H show/hide controls, Esc pause menu (closes open panels first).

Day-skip vote (FML-14): press V by day to vote or withdraw. Votes count once 180 s of the day have passed; the day then ends when at least 60% of the people vote (bots do not vote; one vote when playing solo). A day lasts at most 360 s. The 15-second dusk warning (BAL-05) follows, then night. For a quick test, the debug-only F9 key (host) ends the current phase.

## 2.5D look (branch `proto-2.5d`)
- The rules are still flat 2D (`GameSim` unchanged); only `Main` draws differently: everything with height (trees, rocks, walls, enemies, players) is sorted by the y of its foot, walls have a top and a front face, and bodies stand above their shadows.
